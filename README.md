VELMARIS — a travel poster for a place that isn't there. An art-deco poster of the lagoon where the sun sets through the Ring, a colossal natural stone ring rising out of the sea. `main.py` writes the poster to `/output/entry.png` (1024×1024 PNG); the artwork is rendered procedurally with Pillow at build time and shipped as `entry.png` beside it.

## Run it

```sh
python3 main.py
```
